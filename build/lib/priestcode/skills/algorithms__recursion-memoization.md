# Recursion & memoization

## When to use
Working on recursion & memoization.

## Checklist
- Define the base case and the shrink step clearly; ensure termination.
- Memoize overlapping subproblems; watch recursion depth (convert to iteration if deep).
- Reason about the call tree's size.

## Pitfalls
- Missing/exponential base cases → stack overflow or blowup.
- Re-computing the same subproblems (no memoization).
