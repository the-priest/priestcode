# Web scraping

## When to use
Working on web scraping.

## Checklist
- Respect robots/ToS and rate limits; identify yourself; cache responses.
- Prefer APIs; parse HTML with a real parser; handle pagination and failures.
- Be resilient to layout changes; back off on errors.

## Pitfalls
- Hammering a site gets you blocked/banned.
- Brittle selectors that break on any redesign.
