# NumPy

## When to use
Numerical array work in Python.

## Checklist
- Vectorize with array ops/broadcasting; avoid Python loops over elements.
- Mind dtypes and overflow; understand views vs copies.
- Use the right axis; check shapes.

## Pitfalls
- Integer overflow in fixed dtypes.
- Accidentally mutating a view of another array.
