# App store release

## When to use
Working with App store release.

## Checklist
- Follow App store release conventions for structure, navigation, and state.
- Handle permissions, lifecycle, and offline; keep the UI thread free.
- Test on real devices; follow store review/signing requirements.

## Pitfalls
- Ignoring platform lifecycle/permission rules.
- Only testing on emulators/desktop.
