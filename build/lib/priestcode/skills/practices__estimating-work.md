# Estimating work

## When to use
Sizing a task before committing.

## Checklist
- Break the work down; estimate the pieces; add explicit unknowns/risk buffer.
- Give a range, not a false-precise number; state assumptions.
- Re-estimate as you learn; flag slippage early.

## Pitfalls
- A single number hides the uncertainty.
- Estimating the happy path only, ignoring testing/edge cases.
