# Managing technical debt

## When to use
A codebase accumulating shortcuts.

## Checklist
- Make debt visible (TODOs with context, a debt list); tie paydown to nearby work.
- Fix the debt you keep tripping over; leave code better than you found it.
- Distinguish deliberate, tracked debt from accidental mess.

## Pitfalls
- Invisible debt never gets paid.
- Big refactor-everything projects that never ship.
