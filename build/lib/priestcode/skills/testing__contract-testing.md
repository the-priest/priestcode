# Contract testing

## When to use
Working on contract testing.

## Checklist
- Define the contract; consumer-driven tests; verify the provider against it in CI.
- Version contracts; catch breaking changes before deploy.
- Test both sides.

## Pitfalls
- Integration drift caught only in production.
- Contracts that aren't verified in CI.
