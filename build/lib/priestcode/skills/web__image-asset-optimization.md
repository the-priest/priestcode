# Image & asset optimization

## When to use
Working on image & asset optimization.

## Checklist
- Right formats (WebP/AVIF); responsive sizes; lazy-load below the fold; compress.
- Cache-bust with hashed names; preload critical assets; minify JS/CSS.
- Measure with a performance budget.

## Pitfalls
- Shipping huge unoptimized images.
- Blocking render on non-critical assets.
