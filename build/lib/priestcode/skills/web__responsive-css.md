# Responsive CSS

## When to use
Working with responsive css.

## Checklist
- Mobile-first; flexbox/grid over floats; relative units; fluid images.
- Breakpoints by content, not devices; test at phone width with a side gutter.
- Avoid horizontal scroll.

## Pitfalls
- Fixed pixel widths break on small screens.
- Desktop-only testing.
