# SEO fundamentals

## When to use
Working on seo fundamentals.

## Checklist
- Semantic HTML, unique titles/meta, clean URLs, sitemap, structured data.
- Fast load and mobile-friendly; server-render or pre-render for crawlers.
- Canonical URLs; avoid duplicate content.

## Pitfalls
- Client-only rendering that crawlers can't read.
- Duplicate content without canonicals.
