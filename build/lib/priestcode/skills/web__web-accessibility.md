# Web accessibility

## When to use
Working with web accessibility.

## Checklist
- Semantic HTML; label controls; keyboard operable; visible focus.
- Sufficient color contrast; alt text; ARIA only when semantics fall short.
- Test with a screen reader and keyboard-only.

## Pitfalls
- Div-soup with click handlers isn't keyboard/AT accessible.
- ARIA misused breaks more than it fixes.
