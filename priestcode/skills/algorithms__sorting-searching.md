# Sorting & searching

## When to use
Working on sorting & searching.

## Checklist
- Use the stdlib sort (with a key); sort once to enable binary search / grouping.
- Binary search needs a sorted, monotonic space; mind boundaries.
- Consider counting/bucket sort for bounded keys.

## Pitfalls
- Off-by-one and infinite loops in hand-rolled binary search.
- Re-sorting repeatedly instead of once.
