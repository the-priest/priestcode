# String algorithms

## When to use
Working on string algorithms.

## Checklist
- Know when to use hashing, two-pointers, sliding windows, or a trie.
- Mind Unicode (code points vs bytes vs graphemes); normalize when comparing.
- Avoid quadratic concatenation in loops (use a builder/join).

## Pitfalls
- Byte vs character confusion with Unicode.
- O(n²) string building in a loop.
