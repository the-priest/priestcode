# Backup & restore

## When to use
Working on backup & restore.

## Checklist
- Automate backups; store off-site/encrypted; set retention.
- TEST restores regularly — an untested backup is a hope, not a plan.
- Document RTO/RPO.

## Pitfalls
- Never testing a restore until you need it.
- Backups next to (and deletable with) the data.
