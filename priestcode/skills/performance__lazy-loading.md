# Lazy loading

## When to use
Working on lazy loading.

## Checklist
- Load code/data/images on demand; split bundles; paginate; virtualize long lists.
- Prefetch likely-next; show placeholders.
- Measure the win.

## Pitfalls
- Lazy-loading above-the-fold content hurts UX.
- Waterfalls from serial lazy loads.
