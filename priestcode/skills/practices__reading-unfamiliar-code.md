# Reading unfamiliar code

## When to use
Starting on an unfamiliar project.

## Checklist
- Start at the entry point and the build/test commands; run it first.
- Trace one real request/flow end to end; map the module boundaries.
- Read tests to learn intended behavior; use grep/symbols to navigate; change something small and run it.

## Pitfalls
- Reading top-to-bottom instead of following a flow.
- Changing things before you can run and test them.
